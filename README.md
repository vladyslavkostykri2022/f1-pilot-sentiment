# F1 Pilot Sentiment Analysis

Вебзастосунок для аналізу емоційного стану пілотів Формули-1 на основі аудіофрагментів радіообміну. Система приймає WAV-файл, розпізнає мовлення за допомогою Vosk, виконує базовий сентимент-аналіз тексту та зберігає результат у локальній H2-базі даних.

## Можливості системи

- завантаження аудіофайлу радіообміну у форматі `.wav`;
- розпізнавання мовлення з аудіо за допомогою локальної моделі Vosk;
- визначення тональності повідомлення: `POSITIVE`, `NEGATIVE` або `NEUTRAL`;
- розрахунок рівня стресу пілота в діапазоні від `0.0` до `1.0`;
- відображення впевненості результату аналізу;
- збереження історії аналізів у локальній базі даних;
- перегляд попередніх результатів на сторінці історії;
- демонстраційний WebSocket-дашборд для відображення результатів у режимі реального часу.

## Технології

Проєкт реалізовано як Java Spring Boot застосунок.

Основні компоненти:

- `Java 21` - мова та платформа виконання;
- `Spring Boot 3.3.4` - основа вебзастосунку;
- `Spring Web` - HTTP-контролери та обробка запитів;
- `Thymeleaf` - серверні HTML-шаблони;
- `Spring Data JPA` - робота з базою даних;
- `H2 Database` - локальна файлова база даних;
- `Spring WebSocket` - обмін повідомленнями в реальному часі;
- `Vosk 0.3.45` - локальне розпізнавання мовлення;
- `Maven` - керування залежностями та збірка;
- `Tailwind CSS`, `Font Awesome`, `SockJS`, `STOMP.js` - клієнтська частина інтерфейсу.

Призначення основних файлів і папок:

- `src/main/java/.../controller` - вебконтролери сторінок, обробка завантаження аудіо та WebSocket-повідомлень;

- `src/main/java/.../model` - JPA-моделі даних;
- `src/main/java/.../repository` - репозиторії для доступу до бази даних;
- `src/main/resources/templates` - HTML-сторінки інтерфейсу;
- `src/main/resources/static` - статичні JavaScript-файли;
- `src/main/resources/vosk-model-small-en` - локальна англомовна модель Vosk;
- `data/f1sentiment.mv.db` - файл локальної H2-бази з історією аналізів;
- `Bottas-Bites-Back_..._split` - приклади WAV-фрагментів для тестування.

1. `JDK 21`

3. Браузер: Google Chrome, Microsoft Edge, Firefox або інший сучасний браузер
4. Доступ до інтернету під час першої збірки, щоб Maven завантажив залежності

Перевірка встановлення:

```bash
java -version
```

У результаті `java -version` має бути вказана версія Java `21`.

Розпакуйте архів `f1-pilot-sentiment-main.zip` у зручну папку, наприклад:

Після розпакування переконайтеся, що у корені проєкту є файл:


Windows PowerShell:


Linux або macOS:

Після успішної збірки у папці `target/` буде створено JAR-файл:

Найпростіший спосіб запуску:

```bash
mvn spring-boot:run
```

Цей спосіб рекомендований для демонстрації та локального тестування, оскільки застосунок використовує модель Vosk із папки:

Спочатку зібрати проєкт:

## Робота із застосунком

### Аналіз аудіофайлу

1. Відкрити головну сторінку:

```text
http://localhost:8081
```

2. Вибрати `.wav` файл радіообміну.
3. Вказати `Pilot ID`, наприклад:

```text
LEC
VER
HAM
NOR
```

4. Натиснути кнопку аналізу.
5. Переглянути результат:

- розпізнаний текст;
- тональність;
- рівень стресу;
- впевненість результату.

### Вимоги до аудіофайлу

Поточна реалізація очікує WAV-файл, який може бути прочитаний стандартними засобами Java AudioSystem. Для найкращого результату використовуйте:

- формат `.wav`;
- частоту дискретизації `16000 Hz`;
- один канал, тобто `mono`;
- кодування `PCM`;
- англомовне мовлення, оскільки в проєкті підключена модель `vosk-model-small-en`.

У проєкті вже є приклади аудіофрагментів у папці:

```text
Bottas-Bites-Back_-Plus-All-The-Best-Team-Radio-2019-Australian-Grand-Prix_split/
```

## База даних H2

Проєкт використовує локальну файлову H2-базу даних.

Налаштування з `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:h2:file:./data/f1sentiment;DB_CLOSE_ON_EXIT=FALSE;DB_CLOSE_DELAY=-1
spring.datasource.username=sa
spring.datasource.password=
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console
spring.jpa.hibernate.ddl-auto=update
```

Підключення до H2 Console:

```text
URL: http://localhost:8081/h2-console
JDBC URL: jdbc:h2:file:./data/f1sentiment
User Name: sa
Password: залишити порожнім
```

Таблиці створюються автоматично завдяки параметру:

```properties
spring.jpa.hibernate.ddl-auto=update
```

Щоб очистити історію аналізів, зупиніть застосунок і видаліть файл бази:

```text
data/f1sentiment.mv.db
```

Після наступного запуску база буде створена знову.

## Конфігурація

Основні параметри знаходяться у файлі:

```text
src/main/resources/application.properties
```

### Зміна порту

За замовчуванням застосунок запускається на порту:

```properties
server.port=8081
```

Щоб змінити порт, наприклад на `8080`, замініть значення:

```properties
server.port=8080
```

Після зміни перезапустіть застосунок.

### Обмеження розміру файлу

Зараз дозволено завантажувати файли до `50MB`:

```properties
spring.servlet.multipart.max-file-size=50MB
spring.servlet.multipart.max-request-size=50MB
```

За потреби значення можна збільшити або зменшити.

### Шлях до моделі Vosk

Модель розпізнавання мовлення знаходиться у папці:

```text
src/main/resources/vosk-model-small-en
```

У сервісі `VoskSpeechToTextService` використовується шлях:

```java
new Model("src/main/resources/vosk-model-small-en")
```

Тому під час запуску важливо виконувати команду з кореневої папки проєкту. Якщо переносити застосунок як окремий JAR без вихідних файлів, потрібно також перенести папку з моделлю або змінити шлях до неї у коді.

2. Скопіювати всю папку проєкту на цільову машину.
3. Перейти в корінь проєкту.
4. Виконати:

```bash
mvn spring-boot:run
```

5. Відкрити:

```text
http://localhost:8081
```

Якщо застосунок запущено на сервері, замість `localhost` використовуйте IP-адресу або домен сервера:

```text
http://SERVER_IP:8081
```

### Варіант 2. Розгортання через JAR

1. На машині для збірки виконати:

```bash

```

2. Скопіювати на сервер:

- папку `src/main/resources/vosk-model-small-en`;
- папку `data`, якщо потрібно перенести історію аналізів.


Якщо застосунок запускається на сервері, потрібно дозволити доступ до порту `8081` у firewall.

## Типові проблеми та вирішення

### Порт 8081 вже зайнятий

Ознака: застосунок не стартує, у консолі є повідомлення про зайнятий порт.

Рішення: змінити порт у `application.properties`:

```properties
server.port=8082
```

Після цього відкрити:

```text
http://localhost:8082
```

### Помилка `JAVA_HOME` або неправильна версія Java

Ознака: Maven не запускається або повідомляє про несумісну версію Java.

Рішення:

- встановити JDK 21;
- налаштувати змінну середовища `JAVA_HOME`;
- перевірити командою `java -version`.

### Maven не може завантажити залежності

Ознака: під час `mvn spring-boot:run` або `mvn clean package` виникають помилки завантаження dependency.

Рішення:

- перевірити інтернет-з'єднання;
- повторити команду;
- якщо використовується proxy, налаштувати Maven proxy у файлі `settings.xml`.

### Не знайдено модель Vosk

Ознака: помилка під час старту застосунку, пов'язана з `vosk-model-small-en`.

Рішення:

- запускати команду з кореневої папки проєкту;
- перевірити, що існує папка `src/main/resources/vosk-model-small-en`;
- не перейменовувати й не видаляти папку моделі.

### Аудіофайл не розпізнається

Можливі причини:

- файл не у форматі WAV;
- аудіо має іншу частоту дискретизації або не PCM;
- мовлення не англійською;
- у записі забагато шуму;
- файл занадто великий.

Рішення:

- використати WAV-файл із параметрами `16000 Hz`, `mono`, `PCM`;
- спробувати один із тестових файлів із папки прикладів;
- перевірити, що розмір файлу не перевищує `50MB`.

### Сторінка відкривається без стилів

Ознака: HTML відображається, але без оформлення.

Причина: браузер не має доступу до CDN Tailwind CSS або Font Awesome.

Рішення:

- перевірити інтернет-з'єднання;
- або завантажити потрібні CSS/JS бібліотеки локально та підключити їх у шаблонах.

### Не відкривається H2 Console

Перевірити, що застосунок запущено і в `application.properties` є:

```properties
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console
```

Адреса:

```text
http://localhost:8081/h2-console
```
